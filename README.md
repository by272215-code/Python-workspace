# Python Workspace 🚀
A Collection of beginner-friendly Python mini projects created for learning and practice.
This repository demonstrates basic programming concepts using simple and practical examples.

## 🛠️ Technologies Used
Python Programming 
C Programming 

## Projects Included
🔢 Calculator (calculator.py)
A simple command-line calculator that performs:
Addition
Subtraction
Multiplication
Division
*** Helps in understanding functions and user input handling.

📋 Task Manager (task_manager.py)
A basic task management system where you can:
Add tasks
View tasks
Delete tasks
*** Useful for learning lists and basic CRUD operations.

🆔 ID System (id.py / id_system.py)
A simple system to:
Generate IDs
Store and manage user data
*** Demonstrates logic building and basic data handling.


👟 Blind Shoes Project (Blind.c)
A smart safety project designed for visually impaired people.
This system helps detect obstacles and alert the user to avoid accidents.
🔍 Features
- Obstacle detection using sensors
- Alert system (buzzer / vibration)
- Helps in safe walking
⚙️ How It Works
- Sensors detect nearby obstacles
- If an object is detected within a certain distance
- The system triggers an alert (sound or vibration)
🛠️ Components Used
- Ultrasonic Sensor
- Buzzer / Vibration Motor
- Microcontroller (Arduino compatible logic in C)
